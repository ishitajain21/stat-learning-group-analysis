The dataset that we examine is tracking legal decisions made by either courts or tribunals on the topic of generative AI use in the legal process. Specifically, these cases concern AI hallucination of laws, quotes, or other instances of falsely generated material. We are investigating how the number of such cases has changed over time. 

First, our investigation includes a preliminary exploration of the relationship between the number of cases and specialty (e.g., judge, lawyer, litigant), as well as the number of cases and the subspecialty of law (e.g, contract, tort, tax). We also examine the breakdown between cases that result in professional sanctions and those that do not. These three topics constitute our three data visualizations. 

Next, we use regression to investigate the relationship between time (across the months included in the dataset) and the number of cases. We ask want to know if there is there a trend across time in the number of cases. More specifically, we ask: has the number of documented AI hallucination court cases increased over time? 

Our first statistical analysis is a linear regression model. Using this model, we identify a statistically significant positive relationship between the progression of time and the number of cases identified each month. That is to say, as months progress, the number of monthly cases increases. One significant limitation of this model is that it allows for negative counts, which is impossible when it comes to the actual number of cases per month. To improve upon this model and prevent the prediction of a negative count of cases, our next model uses poisson regression, which can only predict non-negative real values. The poisson regression also yields significant results which indicate that the number of cases reported monthly increases over time. One limitation of this model, however, is that it underestimates the number of cases for the time period from approximately June 2025 through approximately March 2026, but it also predicts too dramatic of an increase in cases month-to-month after March 2026. In other words, the shape of the model does not quite fit the data even though it correctly predicts the overall trend.
