# stat-learning-group-analysis

Shared repository for the Computational Statistics group analysis of documented AI hallucination cases.

## Files

- `analysis.qmd` — group analysis (render to HTML)
- `data/hallucination_cases.csv` — starter data from the assignment

## Workflow

Before working: pull.

While working: save, stage, commit.

Before sharing: pull, then push.

Do not have more than one person edit the same section of `analysis.qmd` at the same time. If Git reports a conflict, resolve it before pushing.
